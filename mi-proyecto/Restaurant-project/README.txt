EVALUACIÓN FINAL: PROYECTO WEB RESTAURANTE SABOR & TRADICIÓN
======================================================================

DESCRIPCIÓN GENERAL:
Página web responsiva e interactiva desarrollada para un restaurante gourmet.
El proyecto incluye un menú navegable con 10 páginas subordinadas,
un carrusel de imágenes en la página principal, efectos interactivos al pasar
el ratón por los productos, modal informativo al hacer clic y un formulario
con validación JavaScript en tiempo real.

CUMPLIMIENTO DE RÚBRICAS:
1. Estructura HTML (Módulos 3 y 4):
   - Uso completo de etiquetas semánticas (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>).
   - Estructura principal en index.html y 10 páginas subordinadas integradas en la navegación.

2. Diseño CSS y Responsividad (Módulos 4 y 5):
   - Integración del framework Bootstrap 5 Grid System.
   - Hoja de estilos personalizada css/styles.css con variables de color y efectos Hover.
   - Diseño adaptable para móviles, tabletas y computadoras.

3. Interacción con JavaScript (Módulo 6):
   - Carrusel dinámico de imágenes en index.html.
   - Resaltado de productos al pasar el cursor (Hover CSS/JS).
   - Apertura de modal con datos dinámicos mediante atributos data-*.
   - Validación de datos e interacción dinámica en el formulario de contacto.

4. Buenas Prácticas (Módulo 7):
   - Estructura modular de carpetas (/css, /js, /img).
   - Comentarios explicativos en HTML, CSS y JS.
   - Código limpio y estandarizado.
