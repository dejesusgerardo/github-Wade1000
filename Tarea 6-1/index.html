Práctica de JavaScript - Evaluación Rúbrica 6.1

Abre la Consola del Desarrollador en tu navegador web para observar la salida e interacción de los programas de JavaScript.

Instrucciones para abrir la consola:

  • Windows / Linux: Presiona F12 o Ctrl + Shift + I
  • Mac: Presiona Cmd + Option + I
  • Cualquier sistema: Clic derecho en la página → Inspeccionar → Pestaña Consola
